# 🚀 Frontend Hub

A frontend learning platform with interactive tools, salary calculator, framework quiz and curated learning paths.

---

## 🚀 Live Demo

👉 **[View Live Demo](https://gemachistesfaye.github.io/Summer-Bootcamp-Projects/frontend-learning-hub)**

---

## ✨ Features

- Modern landing page with hero section
- Industry insights and tech radar
- Structured learning roadmaps
- Salary calculator by role and location
- Framework quiz for JavaScript assessment
- To-do list for managing goals
- Project showcase and mentor profiles
- Contact form

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|----------|
| **HTML5** | Semantic structure |
| **CSS3** | Styling & Layout |
| **TailwindCSS** | Utility-first styling |
| **JavaScript (ES6+)** | Core logic & DOM manipulation |
| **Font Awesome** | Icons |

## ⚙️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/gemachistesfaye/Summer-Bootcamp-Projects.git
   ```
2. Navigate to the folder:
   ```bash
   cd Summer-Bootcamp-Projects/frontend-learning-hub
   ```
3. Open `index.html` in your browser.
