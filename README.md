# Summer Bootcamp – Frontend Projects

Frontend projects built during the **ISHUB AAU Summer Bootcamp 2025**.

📍 Addis Ababa University (AAU) – ISHUB | 📅 July 8 – September 7, 2025

---

## Projects

| # | Project | Description | Tech |
|---|---------|-------------|------|
| 1 | [Task Hub](./personal-task-manager) | Productivity workspace with task management, timer and profile | HTML, TailwindCSS, JS |
| 2 | [Memory Cards](./memory-cards) | Flashcard app with deck management, search and dark mode | HTML, CSS, JS |
| 3 | [Quiz App](./quiz-app) | Multiple-choice quiz with instant results | HTML, CSS, JS |
| 4 | [Expense Tracker](./expense-tracker) | Track daily income and expenses with charts | HTML, CSS, JS, Chart.js |
| 5 | [Smart Exchange](./exchange-rate) | Live currency exchange rate calculator | HTML, CSS, JS, API |
| 6 | [Smart PWD](./smart-pwd) | Cryptographic password generator with vault | HTML, CSS, JS, Web Crypto |

**Live Demos:** [Task Hub](https://gemachistesfaye.github.io/Summer-Bootcamp-Projects/personal-task-manager) | [Memory Cards](https://gemachistesfaye.github.io/Summer-Bootcamp-Projects/memory-cards) | [Quiz App](https://gemachistesfaye.github.io/Summer-Bootcamp-Projects/quiz-app) | [Expense Tracker](https://gemachistesfaye.github.io/Summer-Bootcamp-Projects/expense-tracker) | [Smart Exchange](https://gemachistesfaye.github.io/Summer-Bootcamp-Projects/exchange-rate) | [Smart PWD](https://gemachistesfaye.github.io/Summer-Bootcamp-Projects/smart-pwd)
