## ✨ Features

- Dynamic deck management — create, edit and categorize cards
- Interactive flip animations via click or Spacebar
- Progress tracking with visual progress bar
- Smart navigation with buttons or Arrow Keys
- Real-time search and filter by text or category
- Shuffle deck for randomized learning
- Export/import decks as JSON
- Dark mode toggle
- Offline persistence via `localStorage`
