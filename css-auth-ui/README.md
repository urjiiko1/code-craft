## ✨ Features

- Glassmorphism frosted glass effect on all forms
- Animated background with moving girl on bike
- Falling leaves animation
- Pure CSS toast notifications
- Seamless navigation between pages

---

## ⚙️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/gemachistesfaye/Summer-Bootcamp-Projects.git
   ```
2. Navigate to the folder:
   ```bash
   cd Summer-Bootcamp-Projects/css-auth-ui
   ```
3. Open `index.html` in your browser.
